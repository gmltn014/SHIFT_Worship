## 🌟 프로젝트 개요
SHIFT 찬양팀 웹 포털은 주일 예배 사역의 준비 과정에서 발생하는 소통의 번거로움을 줄이고, 팀원 개개인이 사역에 온전히 집중할 수 있도록 제작되었습니다. 별도의 앱 설치나 회원가입 절차 없이 모바일 브라우저를 통해 실시간으로 최신 콘티와 세션 라인업을 확인하고 소통할 수 있습니다.

---

## 📑 탭별 세부 기능 가이드

### 1. 이번 주 콘티 (This Week)
이번 주일에 진행되는 예배의 핵심 정보와 세션 섬김이 명단을 확인하는 기본 메인 탭입니다.

* **예배 정보 및 콘티 구성**:
  * **일자 및 예배명**: 주일 일자와 해당 예배의 공식 명칭 표기 (예배 미진행 시 취소 사유 안내)
  * **찬양 곡 목록**: 주간 콘티 곡 순서와 곡명, 코드 표기
  * **결단 찬양**: 예배 결단 곡명 표기 및 전용 악보/영상 바로가기 지원
* **사역 링크 원클릭 연결**:
  * 📑 콘티 전체 악보 열기 (구글 드라이브 / PDF)
  * 🎧 유튜브 음원 재생목록 (여러 곡의 음원이 단일 플레이리스트로 자동 묶여 재생)
  * 🎥 실황 모니터링 영상 링크
* **세션 라인업 그리드 (Lineup Grid)**:
  * 인도자, 보컬(최대 4인), 건반(메인/세컨), 드럼, 기타, 베이스, 음향, 방송/중계, 자막, 영상편집 파트별 섬김이 명단 시각화
* **라인업 공유 유틸리티**:
  * **📋 라인업 복사**: 카카오톡 단체 채팅방 공지에 최적화된 서식의 텍스트가 클립보드에 원클릭 복사
  * **🖼️ 이미지 저장**: 보면대 공유나 소장을 위해 세션 라인업 카드를 고화질 PNG 이미지로 자동 캡처 후 다운로드

---

### 2. 아카이브 (Archive)
과거부터 지금까지 진행된 모든 예배와 콘티, 섬김이 내역을 누적 보관하는 검색형 보관소입니다.

* **서브 탭 분리**:
  * **🎵 예배/콘티 아카이브**: 과거 주차별 찬양 곡 목록, 결단 찬양, 악보 및 음원 링크 열람
  * **👥 섬김이(라인업) 내역**: 주차별 세션 및 방송/미디어 파트 참여자 기록 열람
* **다차원 탐색 및 필터링**:
  * **월별 내비게이션 & 전체 보기**: 연/월 단위 이동 및 전체 기간 일괄 조회 토글 지원
  * **인도자 필터링**: 특정 인도자가 이끌었던 예배만 선택 조회
  * **통합 검색**: 곡명, 예배명, 가사 키워드 검색 (결단찬양 포함/제외 옵션 지원)
* **아코디언 뷰**: 카드를 누르면 상세 곡 목록과 음원 링크가 펼쳐져 빠른 스캔 가능

---

### 3. 공지사항 (Notice)
찬양팀의 일정 및 포털 변경 소식을 투명하게 전하는 알림 창구입니다.

* **서브 탭 구성**:
  * **📢 주요 공지**: 정기 연습 일정, 수련회, 공지 사항 등 중요 안내 (상단 고정 핀 기능 지원)
  * **📝 업데이트 노트**: 웹 포털의 버전별 신규 기능, 개선점, 패치 내역 보관
* **버전 자동 연동**: 최신 업데이트 노트 배포 시 헤더 상단의 타원형 버전 뱃지(`vX.X.X`)가 자동으로 동기화

---

### 4. 시프트 명단 (Members)
함께 사역하는 SHIFT 팀원들의 파트 정보와 연락처를 확인할 수 있는 팀원 디렉토리입니다.

* **파트별 대분류 필터링**:
  * **Worship**: 예배인도 및 보컬 싱어
  * **Session**: 건반, 드럼, 기타, 베이스 등 악기 세션
  * **Live Ops**: 현장 음향, 자막, 방송 중계
  * **Post Prod**: 영상 편집 및 미디어 제작
* **팀원 카드 정보**:
  * 팀원명, 소속 파트, 세부 역할 태그(`#메인건반`, `#Leader` 등)
  * **📞 전화 바로걸기**: 모바일에서 터치 시 팀원에게 바로 통화 연결

---

### 5. 익명의견함 (Feedback)
팀의 발전과 소통을 위해 100% 익명으로 운영되는 소통 공간입니다.

* **안전한 익명 접수**:
  * 계정 정보나 기기 정보가 DB에 남지 않는 완전 익명 방식
  * 건의 카테고리 선택 지원 (예배/콘티, 연습/일정, 악기/음향장비, 팀운영/친교, 기타)
* **내 의견 처리 현황 조회**:
  * 내가 접수한 의견의 상태(`접수됨` ➔ `검토중` ➔ `반영완료` ➔ `보류`)와 관리자 코멘트를 본인 기기에서 확인 가능
* **반영 완료 피드**:
  * 건의 내용이 실제 팀 사역에 반영된 사례들을 팀 전체에 공유하여 긍정적 소통 유도

### 6. SHIFT 놀이터 (Playground)
연습실 분위기를 띄우고 팀원 간의 친교와 음악적 편의를 돕는 인터랙티브 엔터테인먼트 공간입니다.

#### ① 🎲 게임 놀이터
* **벌칙 룰렛**: 특정 멤버 1명을 선택하고 여러 벌칙 목록을 돌려 수행할 벌칙을 결정
* **랜덤 룰렛 (수행자 뽑기)**: 벌칙 1개를 고정하고, 활동 중인 팀원 체크박스에서 참여자를 선택해 대상자를 공정하게 추첨
* **박진감 제비뽑기**: 총 인원수와 당첨 수를 설정한 후 카드를 하나씩 뒤집는 미니 게임
* **미니 사다리타기**: 활동 중인 팀원 체크박스로 참가자를 선택해 사다리 타기 결과 매칭

#### ② 📸 SNS 놀이터 (찬양 취향표)
* **나만의 찬양 취향표 작성**:
  * 오늘 묵상한 말씀, 내 인생의 찬양 3곡, 최근 무한반복 중인 추천 찬양 작성 (원하는 항목만 선택 작성 가능)
  * 실명 공개 또는 익명/닉네임 선택 가능
* **인스타 스토리 카드 생성**:
  * 9:16 모바일 스토리 비율로 카드 렌더링
  * 내 갤러리 사진 첨부 또는 웹 이미지 URL을 배경으로 합성하여 고화질 이미지 다운로드 지원
* **포스트잇 보드 피드**:
  * 팀원들이 남긴 취향표가 알록달록한 보드 형태로 나열
  * 추천 찬양 옆 **`▶️ 유튜브 검색/바로듣기`** 버튼을 통해 즉시 음악 감상 가능

#### ③ 🎵 찬양팀 놀이터
* **비주얼 탭 메트로놈 (Metronome)**:
  * 40 ~ 220 BPM 조절 및 Web Audio API 기반 정밀 비프음 출력
  * 시각적 펄스 링(Visual Ring)을 통해 무음 모드에서도 박자 확인 가능
  * 화면을 터치해 템포를 측정하는 **탭 템포(Tap Tempo)** 지원

## ⚙️ 포털 환경설정 (Settings Hub)
헤더 우측의 `⚙️ 설정` 버튼을 통해 개인별 맞춤 설정을 구성할 수 있습니다.

* **화면 스타일 & 글꼴**:
  * 테마 선택: 라이트 모드(☀️) / 다크 모드(🌙)
  * 기본 글꼴 변경: Pretendard(기본 고딕) / S-Core Dream(또렷한 고딕) / Noto Serif KR(단정한 명조)
* **예배 & 연습 편의 (Wake Lock)**:
  * 보면대에 스마트폰/태블릿을 올려두고 콘티를 볼 때 화면이 절전 모드로 꺼지지 않도록 방지
* **🔄 내 기기 기억하기 (기기 간 동기화)**:
  * 회원가입 없이 발급되는 **익명 고유 연동 코드(예: `SHIFT-8492`)** 지원
  * 스마트폰에서 작성한 익명의견 조회 내역과 개인 설정을 PC/노트북으로 원클릭 동기화
* **📲 홈 화면에 앱 추가 (PWA)**:
  * 모바일 브라우저에서 바로가기 아이콘을 홈 화면에 네이티브 앱처럼 설치하도록 안내
